# Changelog

All notable changes to Sage Team will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-12-01

### Added
- 11 fully autonomous AI agents with distinct personas and skill sets
- 27+ world-class skill protocols from Superpowers and Antigravity
- Real-time 2D terminal dashboard using Blessed
- ASCII office map (52x17) with 13 rooms and agent positions
- MCP Playwright integration for visual tracking and screenshots
- Autonomous decision-making engine with confidence scoring
- Skill-aware Claude prompt injection system
- Sprint board with task management and RICE prioritization
- Team chat with contextual role-based interactions
- CLI commands: start, config, team, doctor, screenshot, report
- Agent status animations (16 types)
- Skill trigger matching and auto-activation
- Task-agent matching algorithm based on skill scores
- Visual progress report generation
- Programmatic API for external integration

### Skill Sources
- **Superpowers** (7 skills): TDD, Brainstorming, Debugging, Plans, Dispatch, Verification, Code Review
- **Antigravity** (18 skills): Clean Code, TypeScript, React, Security, Docker, CI/CD, and more
- **Built-in** (2 skills): Browser Automation, Visual Progress Tracking
