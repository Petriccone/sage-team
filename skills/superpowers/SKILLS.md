# Superpowers Skills

> Source: [obra/superpowers](https://github.com/obra/superpowers) — Workflow discipline for coding agents.

## sp-brainstorming — Brainstorming

**Category**: collaboration
**HARD GATE**: No code, no implementation, no scaffolding until design is presented and approved.

**Process**:
1. EXPLORE project context
2. ASK clarifying questions
3. PROPOSE 2-3 approaches with trade-offs
4. PRESENT design incrementally
5. WRITE design doc
6. SPEC REVIEW with iterations
7. USER REVIEWS spec — gate before proceeding

---

## sp-tdd — Test-Driven Development

**Category**: testing
**THE IRON LAW**: No production code without a failing test first.

**Red-Green-Refactor Cycle**:
- **RED**: Write ONE minimal test → confirm FAILURE
- **GREEN**: Write SIMPLEST code to pass → confirm ALL pass
- **REFACTOR**: After green only → remove duplication, improve names

---

## sp-systematic-debugging — Systematic Debugging

**Category**: debugging
**4-Phase Protocol**:
1. **INVESTIGATE**: Reproduce, gather evidence, read code
2. **HYPOTHESIZE**: Rank hypotheses by likelihood
3. **TEST**: Validate ONE hypothesis at a time
4. **FIX**: Minimal targeted fix, verify with tests

## sp-writing-plans — Writing Plans

**Category**: workflow
**Format**: 2-5 minute bite-sized tasks with exact file paths, code samples, and acceptance criteria.

## sp-dispatching-parallel — Parallel Dispatch

**Category**: collaboration

## sp-verification — Verification

**Category**: workflow

## sp-code-review — Code Review

**Category**: development
**Process**: Review against spec, categorize by severity (CRITICAL/HIGH/MEDIUM/LOW), block on critical issues.
